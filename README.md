## Project description
A responsive workshop registration page built with HTML, CSS and JavaScript. It has a two-column
CSS Grid form, HTML validation constraints (email, URL, date, number, password), a workshop dropdown
built from a JavaScript array and loop, custom password-match validation, and an if/else booking
preview (Individual vs Group). It is a browser-only demo: nothing is sent or saved.

## How to run
1. Download or clone this repository.
2. Open `index.html` in a web browser (no installation or internet needed).
3. Fill in the form with invented details and click **Preview registration**.

Files: `index.html`, `styles.css`, `app.js`.
